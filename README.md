# github-actions-ci-practica

API REST CRUD de usuarios con Node.js y Express, con integración continua mediante GitHub Actions (linting, pruebas y reporte de cobertura).

## Endpoints

- GET /health
- GET /users
- GET /users/:id
- POST /users
- PUT /users/:id
- DELETE /users/:id
